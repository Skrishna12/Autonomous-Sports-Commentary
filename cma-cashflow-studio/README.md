# Cashflow Confidential

An interactive study studio for **cash flow statements** — built so a CA Intermediate student warming up for **US CMA** can stay awake.

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8765
```

Then visit `http://localhost:8765`.

## Modes

1. **Night at Meridian** — 8-scene interactive short film. Choices teach profit vs cash, non-cash notes, overdrafts, interest, and working capital.
2. **Three buckets** — classify twelve items as operating / investing / financing. Toggle **CA Inter (AS-3)** vs **US CMA (US GAAP)** in the top bar.
3. **Rebuild the CFS** — indirect method lab from PAT to closing cash (AS-3 presentation).
4. **Ten marks of pain** — exam-style MCQs with explanations.

Progress (XP) is stored in `localStorage` on this machine only.

This is a study aid, not a substitute for ICAI / ICMA study material.
